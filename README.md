# OWASP LLM Top 10 / OWASP Top 10 ノート

このディレクトリには、OWASP の各 Top 10 をもとにした日本語メモを置いています。

現在の `owasp-llm-top10-notes.md` には、以下の 2 系統の内容をまとめています。

- `LLM01` から `LLM10`
  - OWASP `Top 10 for Large Language Model Applications`
  - 各項目に「一言で言うと」「バイブコーディングで起きやすい理由」「攻撃・リスクの概要」「実例・PoC」「対策」「自分のアプリへの応用メモ」を記載
- `A01` から `A10`
  - OWASP `Top 10`（Web Application Security Risks）
  - 各項目に「一言で言うと」「バイブコーディングで起きやすい理由」「攻撃シナリオ」「対策」「自分のアプリへの応用メモ」を記載

## ファイル

- `owasp-llm-top10-notes.md`
  - LLM 向け Top 10 と Web 向け Top 10 を 1 つにまとめたノートです。
  - `実例・PoC` と `自分のアプリへの応用メモ` は、あとから追記しやすいように一部空欄のまま残しています。
